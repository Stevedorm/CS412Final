# CS412Final
This is the Final Np complete project. We have gone in depth on different solutions on the Traveling Saleman Problem.
Within this project contains code, runtime analyses, and presentations on this information. We found solutions for
the optimization version, the approximation version, where we sacrifice accuracy for speed. The optimization
portion of the project was made by Daniel Holtschneider. The approximation portion was made by Shea Parcell and the
augmentation section was completed By Steve Dormandy
