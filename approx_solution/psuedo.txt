STOCHASTIC_GREEDY(dist):
choose random start city s
mark s visited
tour ← [s], current ← s, cost ← 0
while unvisited cities remain:
    for each unvisited v compute weight[v] = 1 / dist[current][v]
    next ← weighted-random-choice(weight)
    add next to tour and mark visited
    cost ← cost + dist[current][next]
    current ← next
cost ← cost + dist[current][s]
return (tour, cost)
